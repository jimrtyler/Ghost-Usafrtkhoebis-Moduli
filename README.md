# 👻 Ghost უსაფრთხოების მოდული
**PowerShell-ზე დაფუძნებული Windows & Azure უსაფრთხოების გამკვრივების ხელსაწყო**

> **პროაქტიური უსაფრთხოების გამკვრივება Windows ბოლო წერტილებისა და Azure გარემოებისთვის.** Ghost უზრუნველყოფს PowerShell-ზე დაფუძნებულ გამკვრივების ფუნქციებს, რომლებიც შეიძლება დაეხმარონ საერთო თავდასხმის ვექტორების შემცირებაში არასაჭირო სერვისებისა და პროტოკოლების გამორთვით.

## ⚠️ მნიშვნელოვანი გათავისუფლება პასუხისმგებლობისგან

**ტესტირება საჭიროა**: ყოველთვის ტესტირება მოახდინეთ Ghost-ის არაწარმოების გარემოში ჯერ. სერვისების გამორთვამ შეიძლება იმოქმედოს ლეგიტიმურ ბიზნეს ფუნქციებზე.

**გარანტიები არ არის**: მიუხედავად იმისა, რომ Ghost მიზნად ისახავს საერთო თავდასხმის ვექტორებს, არცერთ უსაფრთხოების ხელსაწყოს არ შეუძლია ყველა თავდასხმის თავიდან აცილება. ეს არის ერთი კომპონენტი ყოვლისმომცველი უსაფრთხოების სტრატეგიისა.

**ოპერაციული ზეგავლენა**: ზოგიერთ ფუნქციას შეუძლია იმოქმედოს სისტემის ფუნქციონირებაზე. ყურადღებით გადახედეთ ყოველ პარამეტრს განვითარების წინ.

**პროფესიონალური შეფასება**: წარმოების გარემოებისთვის, კონსულტაცია გაიარეთ უსაფრთხოების პროფესიონალებთან იმის უზრუნველსაყოფად, რომ პარამეტრები შეესაბამებოდეს თქვენი ორგანიზაციის საჭიროებებს.

## 📊 უსაფრთხოების ლანდშაფტი

მავნე პროგრამის ზიანმა მიაღწია **57 მილიარდ დოლარს 2025 წელს**, და კვლევები მიუთითებს, რომ ბევრი წარმატებული თავდასხმა იყენებს Windows-ის ძირითად სერვისებსა და არასწორ კონფიგურაციებს. საერთო თავდასხმის ვექტორები მოიცავს:

- **90% მავნე პროგრამის ინციდენტები** მოიცავს RDP-ის ექსპლუატაციას
- **SMBv1 დაუცველობებმა** შესაძლებელი გახადა ისეთი თავდასხმები როგორც WannaCry და NotPetya
- **დოკუმენტის მაკროები** რჩება მავნე პროგრამის მიწოდების პირველად მეთოდად
- **USB-ზე დაფუძნებული თავდასხმები** განაგრძობს ჰაერით განცალკევებული ქსელების დამიზნებას
- **PowerShell-ის ბოროტად გამოყენება** მნიშვნელოვნად გაიზარდა ბოლო წლებში

| `Set-PSRemoting` | მართავს PowerShell დისტანციურ კავშირს | შეიძლება იმოქმედოს დისტანციურ მართვაზე |

| `Set-AdminShares` | მართავს ადმინისტრაციულ გაზიარებებს | შეიძლება იმოქმედოს დისტანციურ ფაილებზე წვდომაზე |
| `Set-Telemetry` | აკონტროლებს მონაცემთა შეგროვებას | შეიძლება იმოქმედოს დიაგნოსტიკურ შესაძლებლობებზე |
| `Set-GuestAccount` | მართავს სტუმრის ანგარიშს | ზოგადად უსაფრთხოა გამორთვა |
| `Set-ICMP` | აკონტროლებს ping პასუხებს | შეიძლება იმოქმედოს ქსელის დიაგნოსტიკაზე |
| `Set-RemoteAssistance` | მართავს დისტანციურ დახმარებას | შეიძლება იმოქმედოს helpdesk ოპერაციებზე |

## 📝ფუნქციების დეტალები

### ძირითადი გამკვრივების ფუნქციები

#### ქსელის სერვისები
- **RDP**: ბლოკავს დისტანციური სამუშაო მაგიდის წვდომას ან პორტს აშლის
- **SMBv1**: აბრუნებს მემკვიდრეობით ფაილების გაზიარების პროტოკოლს
- **ICMP**: არიდებს ping პასუხებს დაზვერვისთვის
- **LLMNR/NetBIOS**: ბლოკავს მემკვიდრეობით სახელის რეზოლუციის პროტოკოლებს

#### აპლიკაციების უსაფრთხოება
- **მაკროები**: აბრუნებს მაკროების შესრულებას Office აპლიკაციებში
- **AutoRun**: არიდებს ავტომატურ შესრულებას მოსახსნელი მედიიდან

#### დისტანციური მართვა
- **PSRemoting**: აბრუნებს PowerShell დისტანციურ სესიებს
- **WinRM**: წყვეტს Windows Remote Management-ს
- **დისტანციური დახმარება**: ბლოკავს დისტანციური დახმარების კავშირებს

#### წვდომის კონტროლი
- **ადმინისტრაციული გაზიარებები**: აბრუნებს C$, ADMIN$ გაზიარებებს
- **სტუმრის ანგარიში**: აბრუნებს სტუმრის ანგარიშის წვდომას
- **USB შენახვა**: ზღუდავს USB მოწყობილობების გამოყენებას

### Azure ინტეგრაცია
```powershell
# Azure მოიჯარეთან დაკავშირება
Connect-AzureGhost -Interactive

# უსაფრთხოების ნაგულისხმევი პარამეტრების ჩართვა
Set-AzureSecurityDefaults -Enable

# პირობითი წვდომის კონფიგურაცია
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# პრივილეგირებული მომხმარებლების აუდიტი
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune ინტეგრაცია (ახალია v2-ში)
```powershell
# Intune-თან დაკავშირება
Connect-IntuneGhost -Interactive

# Intune პოლიტიკების მეშვეობით განვითარება
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

- **ლაბორატორიის გარემო**: ყველა პარამეტრის ტესტი ჯერ იზოლირებულ გარემოში
- **ეტაპობრივი განვითარება**: თანდათან განავითარეთ პრობლემების იდენტიფიცირებისთვის
- **უკან დაბრუნების გეგმა**: დარწმუნდით, რომ შეძლებთ ცვლილებების მოშორებას საჭიროების შემთხვევაში
- **დოკუმენტაცია**: ჩაწერეთ რომელი პარამეტრები მუშაობს თქვენს გარემოში

### პოტენციური ზეგავლენა
- **მომხმარებლის პროდუქტიულობა**: ზოგიერთ პარამეტრს შეუძლია იმოქმედოს ყოველდღიურ სამუშაო პროცესებზე
- **მემკვიდრეობითი აპლიკაციები**: ძველ სისტემებს შეიძლება სჭირდებოდეს გარკვეული პროტოკოლები
- **დისტანციური წვდომა**: განიხილეთ ზეგავლენა ლეგიტიმურ დისტანციურ ადმინისტრირებაზე
- **ბიზნეს პროცესები**: შეამოწმეთ, რომ პარამეტრები არ ირღვევს კრიტიკულ ფუნქციებს

### უსაფრთხოების შეზღუდვები
- **სიღრმის დაცვა**: Ghost არის უსაფრთხოების ერთი ფენა, არა სრული გადაწყვეტა
- **მუდმივი მართვა**: უსაფრთხოება მოითხოვს მუდმივ მონიტორინგსა და განახლებებს
- **მომხმარებლის ტრენინგი**: ტექნიკური კონტროლი უნდა იყოს დაწყვილებული უსაფრთხოების ცნობიერებასთან
- **საფრთხის ევოლუცია**: ახალ თავდასხმის მეთოდებს შეუძლია არიდება მიმდინარე დაცვას

## 🎯 თავდასხმის სცენარების მაგალითები

მიუხედავად იმისა, რომ Ghost მიზნად ისახავს საერთო თავდასხმის ვექტორებს, სპეციფიკური პრევენცია დამოკიდებულია სწორ იმპლემენტაციასა და ტესტირებაზე:

### WannaCry-ს ტიპის თავდასხმები
- **შერბილება**: `Set-Ghost -SMBv1` აბრუნებს დაუცველ პროტოკოლს
- **მოსაზრება**: დარწმუნდით, რომ არცერთ მემკვიდრეობით სისტემას არ სჭირდება SMBv1

### RDP-ზე დაფუძნებული მავნე პროგრამა
- **შერბილება**: `Set-Ghost -RDP` ბლოკავს დისტანციური სამუშაო მაგიდის წვდომას
- **მოსაზრება**: შეიძლება მოითხოვდეს ალტერნატიულ დისტანციური წვდომის მეთოდებს

### დოკუმენტზე დაფუძნებული მავნე პროგრამა
- **შერბილება**: `Set-Ghost -Macros` აბრუნებს მაკროების შესრულებას
- **მოსაზრება**: შეიძლება იმოქმედოს ლეგიტიმურ მაკროთი ჩართულ დოკუმენტებზე

### USB-ით მიტანილი საფრთხეები
- **შერბილება**: `Set-Ghost -USBStorage -AutoRun` ზღუდავს USB ფუნქციონალობას
- **მოსაზრება**: შეიძლება იმოქმედოს ლეგიტიმურ USB მოწყობილობების გამოყენებაზე
